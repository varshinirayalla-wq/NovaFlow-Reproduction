# NovaFlow-Reproduction

## Project Description

NovaFlow is a research implementation focused on
generating object motion from visual observations
and converting the predicted motion into actionable
3D trajectories.

## Objectives

1. Generate object motion videos.
2. Estimate depth information.
3. Track object points.
4. Detect and segment objects.
5. Estimate 3D object movement.
6. Generate robot grasp candidates.
7. Optimize robot trajectories.
8. Evaluate the proposed methodology.

## Technologies

- Python
- NumPy
- OpenCV
- PyTorch (for pretrained model integrations)
- Wan2.1
- MegaSaM
- TAPIP3D
- Grounding DINO
- SAM 2
- GraspGen
- ManiSkill3 / SAPIEN
